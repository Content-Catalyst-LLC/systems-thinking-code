# Modeling Principles

1. Treat platforms as sociotechnical feedback systems, not isolated software tools.
2. Separate engagement, public value, trust, governance capacity, and harm risk.
3. Model feedback over time rather than relying only on static indicators.
4. Preserve portability: default workflows use Python standard library and base R.
5. Use synthetic data to demonstrate methods without profiling real users or platforms.
6. Interpret metrics ethically, including dignity, labor, contestability, privacy, and public consequence.
