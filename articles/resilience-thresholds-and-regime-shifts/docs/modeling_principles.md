# Modeling Principles

This companion repository treats resilience as a dynamic systems property rather than a static label.

Core principles:

1. Model resilience as a stock that can be built or depleted.
2. Track pressure and adaptive capacity separately.
3. Monitor threshold margin, not only current performance.
4. Use early warning indicators such as recovery time, variance, autocorrelation, near misses, and diversity loss.
5. Distinguish recovery, adaptation, and transformation.
6. Make assumptions explicit and auditable.
7. Include distributional vulnerability so aggregate resilience does not hide unequal exposure.
