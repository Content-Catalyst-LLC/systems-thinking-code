# Assumptions and Limitations

This scaffold uses synthetic data and simplified models to demonstrate system dynamics concepts. The examples are not calibrated to a specific empirical system.

## Assumptions

- Stocks change through inflows and outflows.
- Feedback can influence flow rates.
- Delays can alter system behavior.
- Scenario assumptions can be varied to compare trajectories.

## Limitations

- Synthetic data cannot validate real-world policy conclusions.
- Social, ecological, institutional, and political dynamics are simplified.
- Parameter values are illustrative.
- Results should be interpreted as structured reasoning rather than prediction.
