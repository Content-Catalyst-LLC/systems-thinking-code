# Scenario Design Notes

Scenario modeling compares plausible futures under different assumptions. Scenarios are not predictions; they are structured tests of how a system might behave if assumptions, policies, delays, or feedback strengths change.

## Example Scenarios

- Baseline continuation
- Early prevention
- Delayed response
- Capacity investment
- Strong correction
- Low-resource stress case
- High-demand stress case
- Combined structural reform

## Scenario Fields

- `scenario_id`
- `scenario_name`
- `policy_strength`
- `implementation_delay`
- `demand_growth_rate`
- `capacity_investment_rate`
- `feedback_delay`
- `notes`
