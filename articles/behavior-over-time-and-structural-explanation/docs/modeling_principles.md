# Modeling Principles

Behavior-over-time analysis should begin with a clear focal variable, a defined time horizon, and an explicit question about pattern. A trend is not an explanation by itself. Structural explanation requires a plausible mechanism connecting relationships, feedback, stocks, flows, delays, rules, incentives, and boundaries.

## Principles

1. Start with the observed behavior.
2. Separate events from recurring patterns.
3. Track stocks as well as flows.
4. Identify feedback loops that could generate the pattern.
5. Examine delays before judging interventions.
6. Compare alternative structural explanations.
7. Disaggregate trends when averages hide unequal experience.
8. Treat models as aids to inquiry, not final proof.
