# Senge Learning Organization Framework

Peter Senge’s learning organization connects five disciplines with systems thinking.

## Core dimensions

- Personal mastery
- Mental models
- Shared vision
- Team learning
- Systems thinking
- Feedback use
- Psychological safety
- Defensive routines
- Institutional memory
- Trust
- Adaptive capacity
- Ethical purpose

## Diagnosis

A learning organization is not one that merely stores information. It is an organization that can use feedback, examine assumptions, preserve memory, redesign structures, and act with accountable purpose.
