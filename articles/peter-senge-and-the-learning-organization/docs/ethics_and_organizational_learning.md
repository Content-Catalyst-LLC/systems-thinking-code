# Ethics and Organizational Learning

Learning capacity is not automatically ethical. Organizations can learn to manipulate, surveil, exploit, or avoid accountability.

## Ethical requirements

- Include worker voice.
- Protect truth-telling.
- Connect learning to public purpose.
- Avoid using learning tools as surveillance.
- Do not individualize structural burnout.
- Include affected communities where organizational decisions create public consequences.
- Treat organizational learning as accountability, not only performance improvement.
