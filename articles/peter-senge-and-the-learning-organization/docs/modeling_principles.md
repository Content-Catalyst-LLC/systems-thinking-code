# Modeling Principles

This scaffold treats organizational learning as a dynamic systems property rather than a training event.

## Principles

1. Model learning as a stock that accumulates or erodes.
2. Treat feedback use as dependent on quality, safety, and authority.
3. Include defensive routines as learning suppressors.
4. Track institutional memory and forgetting.
5. Distinguish shared vision from compliance rhetoric.
6. Include systems thinking and mental model inquiry.
7. Use models to support dialogue, not surveillance.
8. Connect learning capacity to ethical purpose and accountability.
