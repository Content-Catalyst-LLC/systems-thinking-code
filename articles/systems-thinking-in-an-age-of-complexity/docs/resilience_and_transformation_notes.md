# Resilience and Transformation Notes

Resilience is the capacity to absorb disturbance and continue functioning. Transformation changes the system’s goals, rules, power relations, and feedback structures.

## Distinctions

- Resilience can preserve harmful systems.
- Transformation can change what the system is for.
- Coping is not the same as repair.
- Optimization is not the same as justice.
- Learning without accountability can preserve the status quo.
