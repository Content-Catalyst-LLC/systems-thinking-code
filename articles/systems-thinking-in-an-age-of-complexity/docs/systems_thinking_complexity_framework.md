# Systems Thinking Complexity Framework

This framework connects complexity pressure with resilience, learning, accountability, and transformation.

## Core dimensions

- Interdependence
- Feedback intensity
- Delay pressure
- Adaptation
- Uncertainty
- Redundancy
- Modularity
- Learning capacity
- Trust
- Response variety
- Boundary inclusion
- Accountability
- Harm exposure
- Ethical leverage
- Transformation capacity

## Diagnosis

A complex system should be diagnosed by whether complexity pressure exceeds response capacity, whether harm accumulates, whether feedback can support learning, and whether accountability can transform the structures producing risk.
