# Ethics and Power Analysis

Complex adaptive systems analysis must not become neutral language for describing injustice without accountability.

## Key concerns

- Unequal adaptive capacity
- Burden shifting
- Historical harm
- Institutional resistance
- Co-optation
- Token participation
- Platform amplification
- Surveillance and repression
- Unequal legitimacy
- Public accountability

Emergent harm still requires repair. If a system repeatedly produces harm, institutions have a responsibility to redesign the structures that reproduce it.
