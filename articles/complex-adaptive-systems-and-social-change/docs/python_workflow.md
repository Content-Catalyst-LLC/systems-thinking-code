# Python Workflow

Default Python workflows use only the standard library.

Run:

```bash
python3 python/run_all_complex_adaptive_social_change_workflows.py
```

Expected outputs:

- `outputs/tables/complex_adaptive_social_change_timeseries.csv`
- `outputs/tables/complex_adaptive_social_change_summary.csv`
- additional diagnostic CSVs when optional scripts are present
