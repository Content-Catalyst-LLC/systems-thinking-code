# Leverage Points and Places to Intervene in a System

This companion repository supports the Systems Thinking article **Leverage Points and Places to Intervene in a System**.

The scaffold provides synthetic datasets and multi-language examples for identifying and comparing leverage points across system variables, feedback loops, stocks, flows, delays, rules, incentives, goals, paradigms, and distributional outcomes.

## Intended use

These materials are for education, research demonstration, reproducible systems analysis, and public-interest modeling. They use synthetic data only. They are not decision automation tools and should not be used for surveillance, eligibility screening, employment decisions, individual scoring, or automated governance.

## Structure

- `python/` — leverage diagnostics, intervention comparison, feedback-loop and stock-flow intervention models
- `r/` — leverage-ranking tables, intervention plots, loop summaries, delay visualizations, and distributional summaries
- `julia/` — nonlinear leverage dynamics and structural intervention simulations
- `sql/` — schemas for variables, leverage points, interventions, feedback loops, outcomes, and model runs
- `rust/` — command-line diagnostics scaffold
- `go/` — intervention-pathway runner scaffold
- `cpp/` — efficient leverage scanning and feedback intervention examples
- `fortran/` — recurrence-based leverage model
- `c/` — low-level intervention simulation engine
- `docs/` — modeling notes, ethics notes, assumptions, and responsible-use documentation
- `data/` — synthetic datasets
- `outputs/` — generated outputs placeholder folders
- `notebooks/` — notebook placeholders
