# Optional Advanced Pandas Workflow

The advanced workflow is optional and uses pandas, matplotlib, and openpyxl for richer professional outputs.

Install:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements-advanced.txt
```

Run:

```bash
python python/run_advanced_pandas_workflow.py
```

Outputs include an Excel workbook and advanced PNG figures. Missing dependencies fail gracefully and do not break default smoke tests.
