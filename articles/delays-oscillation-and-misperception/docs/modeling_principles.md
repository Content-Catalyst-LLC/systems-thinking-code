# Modeling Principles

## Purpose

The models in this article folder demonstrate how delay changes system behavior and system interpretation.

## Principles

1. Track behavior over time before explaining single events.
2. Distinguish action-effect delay, information delay, decision delay, implementation delay, perception delay, and recovery delay.
3. Track stocks as well as flows.
4. Test early, delayed, and late interventions.
5. Compare actual system state with perceived system state.
6. Document assumptions clearly.
7. Treat synthetic examples as learning tools, not empirical claims about real systems.
