# Reinforcing and Balancing Dynamics

Companion materials for the Systems Thinking article **“Reinforcing and Balancing Dynamics.”**

This folder supports reproducible examples for:

- reinforcing feedback
- balancing feedback
- limited growth
- delayed correction
- loop dominance
- scenario comparison
- system behavior over time
- responsible systems interpretation

The examples use synthetic data and are designed for learning, documentation, and reproducible article support.

## Optional Advanced pandas Workflow

This article folder includes an optional advanced pandas/matplotlib workflow in `python/run_advanced_pandas_workflow.py`. The default workflows remain dependency-light. To enable advanced outputs, run the repository-level setup script:

```bash
. .venv/bin/activate
python articles/reinforcing-and-balancing-dynamics/python/run_advanced_pandas_workflow.py
```
