# Modeling Principles

1. Treat causal-loop diagrams as hypotheses, not final truth.
2. Use variables that can increase, decrease, accumulate, or deplete.
3. Explain every causal arrow in plain language.
4. Mark link polarity separately from delay.
5. Connect diagram structure to behavior over time.
6. Document boundaries and excluded variables.
7. Use stakeholder knowledge to test and revise maps.
8. Avoid treating complexity as an excuse for avoiding responsibility.
