# Systems Thinking in Public Policy

Companion scaffold for the Systems Thinking article **Systems Thinking in Public Policy**.

This repository models public policy as a dynamic system of policy effort, administrative burden, public trust, implementation capacity, feedback closure, institutional memory, distributional impact, and public value over time.

## Featured workflows

- **Python Workflow: Policy Feedback, Administrative Burden, and Scenario Modeling**
- **R Workflow: Public Policy Indicators, Distributional Diagnostics, and Feedback Visualization**

## Responsible use

Synthetic-data educational scaffold only. Do not use as an operational legal, public-administration, regulatory, budget, benefits, healthcare, housing, climate, or public-policy decision system without domain expertise, transparent assumptions, participatory review, and real data validation.
