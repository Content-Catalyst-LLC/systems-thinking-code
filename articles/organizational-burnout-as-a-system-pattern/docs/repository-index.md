# Repository Index: Organizational Burnout as a System Pattern

GitHub folder: https://github.com/Content-Catalyst-LLC/systems-thinking-code/tree/main/articles/organizational-burnout-as-a-system-pattern/

Primary workflows:

1. Run burnout baseline:
   `python3 python/burnout_system_baseline.py`
2. Run workload, recovery, and hidden-labor checks:
   `python3 python/workload_capacity_model.py`
   `python3 python/recovery_deficit_simulation.py`
   `python3 python/hidden_labor_analysis.py`
3. Run turnover, memory, and redesign scenarios:
   `python3 python/turnover_capacity_feedback.py`
   `python3 python/institutional_memory_decay.py`
   `python3 python/burnout_redesign_scenarios.py`
4. Review generated tables in `outputs/tables/`.
