# Assumptions and Limitations

This scaffold uses synthetic data and simplified formulas for demonstration.

## Limitations

- Synthetic data does not represent a real organization, city, or policy system.
- The model is not a forecasting tool.
- Public systems require qualitative evidence, local data, and affected-community participation.
- A stock-flow model can clarify structure but cannot settle values.
- Model outputs should never override professional, ethical, or democratic judgment.
