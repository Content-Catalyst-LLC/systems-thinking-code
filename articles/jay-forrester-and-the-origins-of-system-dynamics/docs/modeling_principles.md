# Modeling Principles

This scaffold treats system dynamics as a disciplined learning method for stocks, flows, feedback loops, delays, policy resistance, and structural leverage.

## Principles

1. Start with behavior over time, not isolated events.
2. Identify stocks that preserve history.
3. Identify inflows and outflows that change stocks.
4. Map reinforcing and balancing feedback loops.
5. Represent delays explicitly.
6. Test policy interventions against compensating feedback.
7. Use simulation to improve mental models, not to claim certainty.
8. Include boundary critique, participation, and accountability when models affect public systems.
