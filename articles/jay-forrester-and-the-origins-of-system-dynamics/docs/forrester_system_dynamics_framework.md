# Forrester System Dynamics Framework

Jay Forrester’s system dynamics tradition asks how structure produces behavior over time.

## Core dimensions

- Stocks
- Flows
- Feedback loops
- Delays
- Decision rules
- Policy resistance
- Structural leverage
- Institutional learning
- Simulation
- Sensitivity analysis
- Boundary critique
- Participatory review

## Diagnosis

A persistent problem is often a pattern generated by feedback structure. Durable improvement requires changing the structure that reproduces the pattern.
