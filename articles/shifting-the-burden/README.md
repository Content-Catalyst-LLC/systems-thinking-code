# Shifting the Burden

Companion code and documentation for the Systems Thinking article **“Shifting the Burden.”**

This scaffold demonstrates how systems can become dependent on symptomatic relief while fundamental capacity erodes. The examples use synthetic data and reproducible workflows to model:

- problem symptoms
- symptomatic solutions
- fundamental solutions
- capacity stocks
- dependency indicators
- externalized burdens
- relief-plus-repair scenarios
- distributional burden outputs

## Repository purpose

This repository is for systems-thinking education, reproducible modeling, and article support. It is not a forecasting product, operational public-benefits tool, workplace surveillance tool, health decision tool, or policy automation system.

## Suggested workflow

1. Review `docs/shifting_the_burden_framework.md`.
2. Inspect synthetic datasets in `data/`.
3. Run Python examples from the article folder:
   ```bash
   cd articles/shifting-the-burden
   python3 python/shifting_burden_baseline.py
   python3 python/relief_plus_repair_scenarios.py
   ```
4. Optional: run R, Julia, SQL, C, C++, Go, Rust, and Fortran examples if those tools are installed.
