# R Workflow

Base R workflow reads the Python-generated tables and produces summary tables and PNG figures.

Run:

```bash
Rscript r/run_all_intelligent_infrastructure_workflows.R
```

Expected outputs:

- `outputs/tables/intelligent_infrastructure_asset_risk_rank.csv`
- `outputs/tables/intelligent_infrastructure_category_summary.csv`
- PNG figures in `outputs/figures/`
