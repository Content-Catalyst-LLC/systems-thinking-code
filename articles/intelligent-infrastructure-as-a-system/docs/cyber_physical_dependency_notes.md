# Cyber-Physical Dependency Notes

As infrastructure becomes instrumented and connected, digital failure can become physical failure.

## Dependency sources

- Cloud platforms
- Sensor networks
- Control systems
- Telecommunications
- Software vendors
- Identity and access systems
- Data pipelines
- APIs and integration layers
- Cybersecurity tools
- Remote monitoring platforms

## Resilience requirements

- Manual fallback
- Offline continuity
- Segmented control systems
- Incident response
- Vendor audit rights
- Public data governance
- Internal technical capacity
