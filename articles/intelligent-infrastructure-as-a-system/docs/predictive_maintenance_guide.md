# Predictive Maintenance Guide

Predictive maintenance estimates likely asset deterioration and repair needs before failure.

## Useful inputs

- Asset age
- Inspection and condition score
- Load and usage
- Climate exposure
- Failure history
- Maintenance history
- Sensor reliability
- Service criticality
- Redundancy
- Equity priority
- Workforce and budget constraints

## Professional cautions

Predictive models should support, not replace, engineering judgment. Repair priority should include public consequence and equity, not only asset condition.
