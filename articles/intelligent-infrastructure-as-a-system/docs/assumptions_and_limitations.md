# Assumptions and Limitations

This scaffold uses synthetic data and simplified formulas for demonstration.

## Limitations

- Synthetic data does not represent any real infrastructure system.
- Risk scores are illustrative and should not be used for operational decisions.
- Engineering review is required for real asset management.
- Community context is essential for equity analysis.
- Cybersecurity and vendor-risk analysis require local system knowledge.
- Climate exposure modeling must use locally appropriate hazard data.
