# Diagnostic Questions

- What lessons does the institution keep relearning?
- What knowledge would disappear if key people left?
- Do decision records explain rationale and assumptions?
- Does community or frontline feedback reach authority?
- Are postmortems embedded into routines and tools?
- What documentation exists but is not usable?
- Who is repeatedly asked to teach the institution the same lesson?
- What memory is politically inconvenient to preserve?
