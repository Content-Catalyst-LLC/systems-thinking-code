# Repository Index: Institutional Memory and System Learning

GitHub folder: https://github.com/Content-Catalyst-LLC/systems-thinking-code/tree/main/articles/institutional-memory-and-system-learning/

Primary workflows:

1. Run memory baseline:
   `python3 python/institutional_memory_baseline.py`
2. Run memory stock-flow and turnover checks:
   `python3 python/memory_stock_flow_model.py`
   `python3 python/turnover_knowledge_loss.py`
3. Run documentation, feedback, repeated-error, and redesign checks:
   `python3 python/documentation_quality_score.py`
   `python3 python/feedback_loop_closure.py`
   `python3 python/repeated_mistake_risk.py`
   `python3 python/memory_redesign_scenarios.py`
4. Review generated tables in `outputs/tables/`.
