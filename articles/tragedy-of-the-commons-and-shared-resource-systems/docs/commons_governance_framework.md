# Commons Governance Framework

A shared resource system should be analyzed through:

- resource boundaries;
- user boundaries;
- use intensity;
- regeneration or repair rate;
- monitoring quality;
- rule legitimacy;
- sanctions and conflict resolution;
- participation;
- restoration obligations;
- distribution of benefit, burden, and voice.

A commons is not the same as unmanaged open access. Commons governance is a system of shared responsibility.
