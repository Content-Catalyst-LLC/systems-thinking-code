# Sensitivity Analysis Framework

1. Define intervention outcomes.
2. Register parameters and assumptions.
3. Classify uncertainty and influence.
4. Run local sensitivity checks.
5. Run broad scenario or global checks.
6. Search for thresholds.
7. Compare robustness across intervention pathways.
8. Disaggregate outcomes by affected groups.
9. Document fragile assumptions.
10. Redesign the intervention for robustness and repair.
