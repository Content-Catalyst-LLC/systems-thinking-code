# Systems Thinking in AI and Technology

This article repository models AI and technology systems as sociotechnical systems shaped by data, models, infrastructure, governance, institutions, labor, feedback loops, drift, group-level outcomes, and contestability.

## Default workflows

The default Python workflows use only the Python standard library. The default R workflows use base R only. These are intended to run in constrained environments without package installation.

## Optional advanced layer

The optional advanced workflow can use pandas, matplotlib, and openpyxl when installed. It is not required for the smoke test.

## Responsible use

The synthetic examples are for public-interest systems analysis, institutional learning, responsible AI review, and reproducible methods demonstration. They are not decision tools for hiring, lending, policing, healthcare triage, education placement, immigration, benefits eligibility, employee surveillance, or individual risk classification.
