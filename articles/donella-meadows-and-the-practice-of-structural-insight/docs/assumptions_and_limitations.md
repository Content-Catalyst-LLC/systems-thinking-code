# Assumptions and Limitations

This scaffold uses synthetic data and simplified formulas for demonstration.

## Limitations

- Synthetic data does not represent a real ecological, institutional, or social system.
- The model is not a forecasting tool.
- Leverage scoring is illustrative and should be debated.
- Real sustainability analysis requires local evidence, ecological expertise, historical context, public participation, and ethical review.
- Model outputs should never override professional, ecological, or democratic judgment.
