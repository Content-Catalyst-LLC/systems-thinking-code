# Leverage Points Guide

Meadows’s leverage-point framework warns that people often push on weak leverage points while ignoring stronger ones.

## Practical hierarchy

- Parameters: numbers, budgets, rates, targets
- Buffers: reserves, redundancy, stock size
- Information flows: who knows what and when
- Rules: incentives, rights, access, accountability
- Self-organization: ability to create new structure
- Goals: what the system is trying to achieve
- Paradigms: what the system assumes is real and valuable

A good diagnostic asks whether an intervention changes the structure that reproduces the problem.
