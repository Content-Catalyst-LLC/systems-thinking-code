# Fixes That Fail Framework

## Core structure

- Problem symptom increases pressure.
- Quick fix reduces the symptom in the short term.
- Quick fix creates a delayed consequence.
- Delayed consequence increases the original problem or creates a related problem.
- The system repeats the fix because it previously appeared to work.

## Leverage points

- Extend the evaluation horizon.
- Track delayed consequences.
- Pair quick relief with structural repair.
- Reduce dependence on the fix.
- Build the supporting stock that the fix depletes.
- Include affected groups in defining success.
