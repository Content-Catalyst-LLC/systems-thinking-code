# Urban Systems: Congestion, Housing, and Infrastructure

This article folder contains reproducible, professional-oriented systems-analysis workflows for urban systems: congestion, induced demand, housing affordability, infrastructure condition, displacement pressure, climate risk, access, and resilience.

The default workflows are dependency-light and designed to run in constrained environments:

- Python default workflows use only the Python standard library.
- R default workflows use base R only.
- Optional advanced Python workflow uses pandas, matplotlib, and openpyxl when a virtual environment is installed.
- Julia, SQL, Go, Rust, C, C++, and Fortran examples provide compact cross-language systems modeling and validation examples.

These materials use synthetic data and scenario models for methodological demonstration, planning education, systems diagnostics, and reproducible workflow design. They are not official forecasts and should be adapted and validated with local data before decision use.
