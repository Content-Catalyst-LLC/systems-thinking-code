# Article Notes

Article: Causality in Systems Thinking

Core concepts represented in this companion folder:

- linear causality and its limits
- circular causality and feedback
- multiple causes and causal roles
- proximate causes and structural causes
- delay, accumulation, and hidden causality
- thresholds, tipping points, and nonlinearity
- path dependence and historical causality
- counterfactual thinking and intervention
- causal evidence and responsible explanation
- ethics, blame, and responsibility

Recommended companion workflows:

1. Use Python to map causal loops and simulate delayed effects.
2. Use R to compare counterfactual scenarios and visualize thresholds.
3. Use Julia to explore dynamic causal feedback.
4. Use SQL to organize causal variables, relationships, scenarios, and model runs.
5. Use systems languages for efficient diagnostics, recurrence, and causal-pathway examples.
