# Responsible Use

Boundary and problem-frame models can shape policy, institutional decisions, resource allocation, technology governance, and public interpretation.

Use these materials responsibly:

- Do not treat synthetic examples as empirical proof.
- Do not exclude affected communities because they are difficult to quantify.
- Do not use narrow boundaries to hide externalized harms.
- Document assumptions, exclusions, and uncertainty.
- Treat model outputs as supports for deliberation, not automatic answers.
