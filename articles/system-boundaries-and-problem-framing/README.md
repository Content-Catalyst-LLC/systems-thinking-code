# System Boundaries and Problem Framing

Companion materials for the article **“System Boundaries and Problem Framing.”**

This article examines how boundary choices and problem frames shape systems analysis, evidence, accountability, intervention design, ethics, and governance.

## Repository Contents

```text
python/    boundary sensitivity, frame comparison, stakeholder diagnostics, externality accounting, cross-scale analysis
r/         boundary comparison tables, stakeholder matrices, externality plots, frame summaries
julia/     dynamic boundary and nonlinear frame-sensitivity examples
sql/       schemas for boundaries, frames, stakeholders, externalities, scenarios, indicators, and model runs
rust/      command-line boundary diagnostics scaffold
go/        frame-pathway utility scaffold
cpp/       efficient boundary-network and frame-sensitivity examples
fortran/   recurrence and boundary-model examples
c/         low-level boundary simulation utilities
docs/      modeling principles and article notes
data/      synthetic datasets
outputs/   generated outputs
notebooks/ notebook placeholders
```

## Purpose

The goal is to make boundary critique reproducible and explicit. The examples are synthetic and educational. They are intended to show how conclusions can change when system boundaries, stakeholder inclusion, externalized costs, and time horizons change.
