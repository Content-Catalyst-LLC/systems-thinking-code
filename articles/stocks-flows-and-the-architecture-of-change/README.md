# Stocks, Flows, and the Architecture of Change

Companion repository scaffold for the Systems Thinking article **Stocks, Flows, and the Architecture of Change**.

This folder contains reproducible examples for stock-flow simulation, accumulation and depletion, feedback-controlled flows, delayed stock perception, policy scenarios, stock-flow diagnostics, and multi-language systems-analysis scaffolds.

## Folder structure

- `python/` — stock-flow simulation, accumulation/depletion, feedback-controlled flows, delayed perception, policy scenarios, diagnostics
- `r/` — stock-flow plots, accumulation/depletion visualization, inflow/outflow summaries, delayed response, scenario comparison
- `julia/` — continuous stock-flow and nonlinear accumulation examples
- `sql/` — schemas for stocks, flows, observations, feedback controls, scenarios, and model runs
- `rust/`, `go/`, `cpp/`, `fortran/`, `c/` — systems diagnostics and low-level simulation scaffolds
- `docs/` — modeling principles, article notes, framework, assumptions, and responsible-use guidance
- `data/` — synthetic datasets
- `outputs/` — generated outputs placeholder
- `notebooks/` — notebook placeholders

## Responsible use

These examples use synthetic data for educational systems-thinking workflows. They are intended for conceptual modeling, reproducible demonstrations, and learning-oriented analysis, not for automated decisions about people, communities, employment, benefits, discipline, surveillance, or access to essential services.
