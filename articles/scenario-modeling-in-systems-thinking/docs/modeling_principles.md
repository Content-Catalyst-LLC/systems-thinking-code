# Modeling Principles

Scenario modeling is a structured way to reason about plausible futures under uncertainty.

## Core principles

1. Treat every scenario as conditional.
2. Document assumptions explicitly.
3. Compare trajectories rather than only endpoints.
4. Include stocks, flows, delays, feedback, and boundaries.
5. Separate baseline continuation from intervention pathways.
6. Include stress cases, not only preferred futures.
7. Examine distributional effects across groups, places, and generations.
8. Use models to improve judgment rather than to claim certainty.
