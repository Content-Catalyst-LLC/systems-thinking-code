# Assumptions and Limitations

This repository uses synthetic scenario models to demonstrate systems-thinking concepts. The climate model is simplified and should not be interpreted as an official projection.

Key limitations:

- Simplified CO2 conversion and sink behavior.
- Simplified radiative forcing and temperature response.
- Synthetic vulnerability and adaptation indices.
- No regional spatial model.
- No calibrated uncertainty analysis.
- No replacement for IPCC, national, regional, engineering, or peer-reviewed climate-risk models.

Professional use requires validated data, domain review, uncertainty treatment, and fit-for-purpose modeling.
