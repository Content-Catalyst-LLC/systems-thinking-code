# Validation Plan

Default validation checks include:

- generated row counts;
- required column checks;
- non-negative emissions checks;
- positive CO2 concentration checks;
- scenario summary generation;
- Python smoke test;
- optional base R smoke test when Rscript is installed;
- optional pandas workflow with graceful dependency handling.

Additional professional validation should include parameter review, comparison with external scenarios, uncertainty analysis, and peer/domain review.
