# Objective Function Notes

Objective functions are simplified representations of system goals. In real institutions, goals are rarely captured by one equation, but formal comparison can clarify how different priorities change outcomes.

Examples:

- Narrow throughput objective: rewards speed and cost control.
- Access-and-dignity objective: rewards access, dignity, burden reduction, and harm prevention.
- Resilience-and-repair objective: rewards long-term capacity, buffers, repair, and reduced externalized harm.

The objective function is not neutral. Choosing what to optimize is an ethical and political act.
