# Repository Index: Systems Thinking in Governance and Public Institutions

GitHub folder: https://github.com/Content-Catalyst-LLC/systems-thinking-code/tree/main/articles/systems-thinking-in-governance-and-public-institutions/

Primary workflows:

1. Run governance baseline:
   `python3 python/governance_system_baseline.py`
2. Run burden, trust, and coordination checks:
   `python3 python/administrative_burden_index.py`
   `python3 python/public_trust_stock_flow.py`
   `python3 python/coordination_network_analysis.py`
3. Run feedback, capacity, public value, and redesign checks:
   `python3 python/policy_feedback_closure.py`
   `python3 python/institutional_capacity_model.py`
   `python3 python/public_value_scorecard.py`
   `python3 python/governance_redesign_scenarios.py`
4. Review generated tables in `outputs/tables/`.
