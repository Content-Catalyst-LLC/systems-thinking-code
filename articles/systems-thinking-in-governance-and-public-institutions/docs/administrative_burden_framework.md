# Administrative Burden Framework

Administrative burden includes:

- Learning costs: discovering rights, eligibility, rules, documents, and procedures.
- Compliance costs: completing forms, proving status, attending appointments, navigating systems.
- Psychological costs: stigma, uncertainty, fear, humiliation, frustration, and distrust.
- Digital burden: portals, uploads, passwords, access, connectivity, and interface difficulty.
- Appeal burden: contesting errors, understanding rights, and securing meaningful recourse.
