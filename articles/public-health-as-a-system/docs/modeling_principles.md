# Modeling Principles

This repository treats public health as a dynamic system rather than a collection of isolated health indicators.

Core principles:

1. Model population health through stocks and flows: susceptible, infected, recovered, care capacity, trust, vulnerability, and prevention value.
2. Track care capacity and workforce stress as system constraints, not afterthoughts.
3. Treat public trust as a stock that affects cooperation, care-seeking, uptake, and crisis response.
4. Include vulnerability and equity because population averages can hide concentrated harm.
5. Use scenario comparison to evaluate timing, prevention, capacity, trust, and integrated equity strategies.
6. Keep default workflows dependency-light and smoke-testable.
7. Put pandas/matplotlib/openpyxl outputs behind an optional advanced layer.
