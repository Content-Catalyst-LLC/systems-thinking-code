# Optional Advanced Pandas Workflow

The advanced workflow uses pandas, matplotlib, and openpyxl for grouped summaries, figures, and workbook exports.

It is intentionally optional so the default repository remains robust on systems without Python packages installed.

Run:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements-advanced.txt
python python/run_advanced_pandas_workflow.py
```
