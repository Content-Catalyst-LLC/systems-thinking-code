# Article Notes

Article: What Is Systems Thinking?

Core concepts represented in this companion folder:

- systems as interdependent structures
- parts, relationships, boundaries, and purpose
- reinforcing and balancing feedback
- stocks, flows, accumulation, and delay
- emergence, adaptation, and nonlinearity
- mental models and system interpretation
- ethical and governance implications
- practical systems inquiry

Recommended companion workflows:

1. Use Python to simulate feedback and stock-flow behavior.
2. Use R to compare scenarios and visualize delay effects.
3. Use Julia to explore nonlinear feedback.
4. Use SQL to organize variables, causal edges, indicators, scenarios, and model runs.
5. Use systems languages for diagnostics, recurrence, simulation, and network utilities.
