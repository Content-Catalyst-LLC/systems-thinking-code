# Validation Plan

1. Replace synthetic parameters with observed data or stakeholder-validated estimates.
2. Check missingness, outliers, and measurement definitions.
3. Validate whether variables are bounded appropriately.
4. Compare model behavior with historical behavior-over-time data.
5. Test sensitivity to policy delay, feedback closure, burden reduction, and capacity investment.
6. Review distributional effects with affected communities or domain experts.
7. Record assumptions and model revisions in version control.
