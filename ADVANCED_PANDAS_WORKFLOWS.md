# Optional Advanced pandas Workflows

This repository includes dependency-light professional workflows by default and an optional advanced pandas/matplotlib layer for richer analysis.

## Install advanced dependencies

```bash
cd ~/Downloads/systems-thinking-code
./scripts/setup_advanced_python_env.sh
. .venv/bin/activate
```

## Run all advanced workflows

```bash
python scripts/run_all_advanced_pandas_workflows.py
```

## Design rule

Default article workflows should not require pandas. Advanced workflows may use pandas, numpy, matplotlib, and openpyxl when a virtual environment is installed. Missing advanced dependencies should produce clear setup instructions rather than breaking the main smoke test.
