# Policy Timing Framework

## Core timing questions

- When is the policy adopted?
- When does implementation begin?
- When does affected practice change?
- When do leading indicators move?
- When do lagging outcomes become visible?
- When do accumulated stocks change?
- When should evaluation occur?
- When should correction occur?

## Practical outputs

- Timing map
- Lag inventory
- Indicator matrix
- Early-warning dashboard
- Scenario comparison
- Adaptive correction schedule
