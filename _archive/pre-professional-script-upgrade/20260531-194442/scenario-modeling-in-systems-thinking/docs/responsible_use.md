# Responsible Use

These materials are for synthetic-data research, systems-learning demonstrations, and reproducible modeling practice.

They are not decision automation tools. They should not be used to make individual determinations about benefits, employment, eligibility, risk, discipline, surveillance, service access, or rights.

Scenario models should be reviewed with domain experts, implementers, affected communities, and decision-makers. Assumptions, uncertainty, distributional consequences, and limitations should be documented before any policy use.
