# Diagnostic Questions

- What public value is the system supposed to produce?
- Who carries administrative, time, emotional, digital, or appeal burden?
- Where does public feedback originate, and where does it stop?
- What stocks of trust, capacity, memory, and legitimacy are being built or depleted?
- Which institutional boundaries create gaps or burden shifting?
- Whose knowledge defines the problem?
- Does accountability produce learning and repair, or only blame and compliance?
- What crisis vulnerabilities were created in routine governance?
