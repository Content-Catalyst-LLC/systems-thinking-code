# Modeling Principles

This scaffold treats governance as a dynamic public system rather than a set of isolated programs. The examples use synthetic data and are designed for learning, not auditing real agencies.

Key modeling principles:

1. Measure public burden outside the institution, not only agency workload.
2. Treat trust, capacity, legitimacy, institutional memory, and infrastructure as stocks.
3. Model feedback closure: received, interpreted, acted upon, embedded, and remembered.
4. Compare pressure-only responses with structural redesign.
5. Include equity, dignity, access, resilience, and public value in evaluation.
