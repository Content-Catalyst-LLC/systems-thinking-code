# Paradigms and Goals Framework

Use this framework to diagnose deep system structure:

1. What does the system say it values?
2. What does the system repeatedly optimize under pressure?
3. What metrics define success?
4. What harms are normalized or externalized?
5. Whose knowledge counts as evidence?
6. What alternative futures are dismissed as unrealistic?
7. What operating goal explains observed behavior over time?
8. What paradigm makes the current system feel natural?
9. What new goal would redirect feedback and rules?
10. What accountability mechanisms would prevent symbolic reform?
