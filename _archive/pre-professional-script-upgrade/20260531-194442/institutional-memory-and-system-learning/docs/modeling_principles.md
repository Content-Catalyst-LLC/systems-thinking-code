# Modeling Principles

This scaffold treats institutional memory as a dynamic stock that can accumulate, decay, fragment, or become obsolete. The examples use synthetic data and are designed for learning, not auditing real institutions.

Key modeling principles:

1. Distinguish stored information from usable memory.
2. Track learning retention, feedback closure, decision rationale, documentation quality, and authority connection.
3. Include tacit knowledge, turnover risk, repeated errors, and memory bottlenecks.
4. Compare documentation-only interventions with memory-authority integration.
5. Avoid using memory analysis for blame; use it to improve system learning and repair.
