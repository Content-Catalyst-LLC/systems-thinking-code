# Modeling Principles

Model shared resource systems as stocks, flows, users, rules, monitoring, and restoration—not only as isolated extraction choices.

Key principles:

1. Make the shared stock explicit.
2. Distinguish individual benefit from shared cost.
3. Model replenishment, regeneration, or repair.
4. Represent governance rules and monitoring quality.
5. Include distributional impacts and voice in governance.
6. Treat open access and governed commons as different institutional forms.
7. Document assumptions and limits clearly.
