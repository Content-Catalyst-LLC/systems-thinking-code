# Responsible Use

Use these materials for systems learning, public-interest modeling, stewardship design, and reproducible analysis.

Do not use this scaffold for:

- surveillance of resource users;
- enforcement targeting;
- punitive scoring;
- individual-level eligibility or access decisions;
- automated sanctions;
- claims about real communities without evidence and participation.

Commons governance should protect shared resources while respecting rights, voice, fairness, and repair obligations.
