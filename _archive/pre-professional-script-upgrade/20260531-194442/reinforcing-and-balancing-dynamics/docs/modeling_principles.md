# Modeling Principles

## Purpose

These examples demonstrate how reinforcing and balancing feedback structures can generate system behavior over time.

## Principles

1. Begin with behavior over time.
2. Define variables that can increase or decrease.
3. Distinguish reinforcing loops from balancing loops.
4. Document delays and limits.
5. Treat models as structured inquiry, not final truth.
6. Use synthetic data responsibly.
7. Interpret outputs with attention to power, distribution, and ethics.
