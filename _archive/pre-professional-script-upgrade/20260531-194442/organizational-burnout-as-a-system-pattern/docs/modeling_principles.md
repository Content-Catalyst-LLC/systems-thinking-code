# Modeling Principles

This scaffold treats burnout as a dynamic system pattern involving stocks, flows, feedback, and delays. The examples use synthetic data and are designed for learning, not diagnosis of real employees.

Key modeling principles:

1. Measure workload beyond visible tasks.
2. Treat human capacity as a stock that can be depleted or restored.
3. Include recovery, hidden labor, emotional load, rework, turnover, and institutional memory.
4. Compare redesign scenarios instead of relying on wellness-only responses.
5. Avoid individual-level surveillance or punitive interpretation.
