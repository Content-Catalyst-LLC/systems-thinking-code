# Modeling Principles

This scaffold treats success-to-the-successful dynamics as feedback structures, not as individual-level judgments. Models should document starting conditions, resource flows, evaluation rules, network effects, and distributional consequences.

Core principles:

1. Model starting conditions explicitly.
2. Separate performance from resources, visibility, credibility, and opportunity.
3. Track feedback strength over time.
4. Compare performance-only allocation with need-adjusted and capacity-building alternatives.
5. Report distributional effects and advantage gaps.
6. Avoid individual ranking or punitive interpretation.
