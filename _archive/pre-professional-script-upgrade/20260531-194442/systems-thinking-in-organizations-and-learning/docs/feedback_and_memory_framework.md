# Feedback and Memory Framework

Useful organizational learning requires:

1. Feedback signals that are timely, trustworthy, and specific.
2. Interpretive capacity to understand what the feedback means.
3. Authority to change routines, rules, incentives, tools, or workload.
4. Institutional memory that preserves lessons beyond individual tenure.
5. Review systems that embed lessons into process, onboarding, and decision records.
