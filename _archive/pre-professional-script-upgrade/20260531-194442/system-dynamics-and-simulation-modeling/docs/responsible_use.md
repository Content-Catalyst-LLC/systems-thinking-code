# Responsible Use

These materials are designed for education, research prototyping, transparent systems modeling, and reproducible demonstration.

Do not use these examples as automated decision tools. Real systems require domain expertise, stakeholder participation, ethical review, data governance, uncertainty analysis, and public accountability.

Models should clarify assumptions, not hide them. Simulation output should be interpreted with humility and should be reviewed against evidence, lived experience, institutional context, and affected-stakeholder knowledge.
