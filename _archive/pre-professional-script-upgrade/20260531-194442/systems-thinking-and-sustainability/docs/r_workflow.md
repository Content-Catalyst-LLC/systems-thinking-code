Use R for indicator diagnostics, scenario summaries, stock-flow tables, sensitivity rankings, distributional justice tables, resilience summaries, and publication-ready CSV exports.

Primary scripts:

- `sustainability_indicator_plots.R`
- `scenario_comparison_visualization.R`
- `stock_flow_summary_tables.R`
- `sensitivity_results_tables.R`
- `distributional_justice_plots.R`
- `resilience_diagnostics_summary.R`
- `export_sustainability_tables.R`
