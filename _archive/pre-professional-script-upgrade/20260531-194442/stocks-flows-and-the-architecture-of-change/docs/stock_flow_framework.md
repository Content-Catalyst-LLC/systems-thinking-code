# Stock-Flow Framework

Use this sequence for stock-flow analysis:

1. Identify the focal behavior.
2. Name the stock that accumulates or depletes.
3. Identify inflows.
4. Identify outflows.
5. Compare net change.
6. Map feedback controls.
7. Identify delays.
8. Test scenarios.
9. Evaluate distributional effects.
10. Confirm whether the stock actually changed.
