# Modeling Principles

1. Name the stock before modeling the flow.
2. Track both inflows and outflows.
3. Evaluate net change, not activity alone.
4. Identify feedback controls that change flow rates.
5. Document delays between flow changes and visible stock change.
6. Test scenarios over time rather than relying on a single-period snapshot.
7. Treat models as hypotheses that require evidence, context, and revision.
